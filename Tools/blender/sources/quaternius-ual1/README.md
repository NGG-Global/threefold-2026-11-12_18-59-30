# Universal Animation Library (Standard), by Quaternius

`UAL1_Standard.fbx` is the source file for `Tools/blender/build_mage.py`: a 65-bone humanoid
rig, a mannequin body and 43 in-place animations. The `_RM` (root motion) variant is not used,
because the CharacterController moves the character.

- Author: Quaternius, https://quaternius.com/packs/universalanimationlibrary.html
- Licence: CC0 1.0 Universal (public domain dedication), see `License.txt`.
- Unchanged from the "Universal Animation Library [Standard]" download, folder `Unity/`.

This folder is outside `Assets/`, so Unity does not import it.

# Universal Animation Library 2 (Standard), by Quaternius

`UAL2_Standard.fbx` supplies the `ClimbUp_1m` animation (renamed `ClimbUp`) to
`Tools/blender/build_mage.py`. It uses the same 65-bone rig as the first library.

- Author: Quaternius, https://quaternius.com/packs/universalanimationlibrary2.html
- Licence: CC0 1.0 Universal (public domain dedication), see `License.txt`.
- Unchanged from the "Universal Animation Library 2 [Standard]" download, folder `Unity/`.

This folder is outside `Assets/`, so Unity does not import it.
